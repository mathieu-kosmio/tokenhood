# Interfaces

All interfaces are bilingual FR/EN, responsive and accessible. They are described by space and by development lot.

| Space | Screens | Lot |
| --- | --- | --- |
| Public | Home, catalogue of active projects, project page (missions, impact, summarised agreement), public decisions, charter, compatibility register | 1 to 3 |
| Account | Registration, profile, languages, conflicts of interest, declared agents, authorisations, pledges, cap level shown before the session | 1 and 2 |
| Governance | Dashboard, requests by category, request page (options, comments, vote), register of delegated decisions, mandates, common pool allocation | 1 |
| Contributor | Available missions, attempts in progress, feedback to handle, verifications performed, reputation by skill | 2 |
| Project lead | Project console: mission scoping, flow limits, attempt tracking, approval queue, project skills, 30-day feedback, contractual health | 2 and 3 |
| Selection | Recording of a manual admission (lot 3); application, tracking, committee space, generation and signature of the agreement (lot 4) | 3 and 4 |
| Operations | Operational commitments, owners, substitutes | 1 |
| Administration | Moderation, incidents, emergency freeze, scales, templates | 1 to 4 |

The governance console is the first interface produced: from the bootstrap onwards, it is used to handle the questions of the agents developing the platform, first through the register of delegated decisions.
