# Risks and open questions

| Risk | Severity | Mitigation |
| --- | --- | --- |
| Scoping, review and integration workload greater than the gain for the maintainer | High | Net value measured, flow limits, 30-day feedback, scoping missions entrusted to agents |
| Insufficient bootstrap capacity | High | Core of committed contributors before lot 1, lot 0 gate conditional |
| Promises perceived as guarantees | High | Guarantee matrix, cap levels, compatibility register, display of the nature of each figure |
| No eligible reviewer in a small community | Medium | Explicit waiting, alert, reduced production, recruitment of reviewers; traced exemptions only |
| Changes in AI providers' terms | Medium | No credential handled, official client, dated register, recurring watch |
| Slow decisions blocking agents | Medium | Decision categories, mandated delegates, rule of conduct for agents |
| Maturity of tokenpool | Medium | Protocol compatibility rather than dependency, TH-006 audit |
| Leak of sensitive data to a contributor's model | Medium | No KYB document and no non-public personal data in a mission package |
| Collusion and inflated reputation | Medium | Random assignment, exclusions, sampling audit, sanctions |
| Fragile operational continuity | Medium | Table of operational commitments, substitutes, review at each gate |

**Open questions, owner and deadline**

| Question | Owner | Deadline |
| --- | --- | --- |
| Hosting: provider, coverage of costs, fallback | Tokenhood project lead | Lot 0 gate |
| Licence of Tokenhood's code (AGPL-3.0 or permissive) | Provisional governance | Lot 0 gate |
| Entry thresholds for the contributors' college, mandates, end of the founders' period | Provisional governance | Lot 1 gate |
| Token-equivalent scales for subscriptions | Governance, on a `governance.estimation` assessment | Lot 2 gate |
| Signatory structure for agreements (Kosmio, then a dedicated association?) | Tokenhood project lead | Before the admission of the external project (lot 3) |
| Legal validation of the agreement, the signature and the terms of use | Tokenhood project lead | Before the admission of the external project (lot 3) |
| KYB of collectives without a legal structure: identity of two maintainers or fiscal host required | Selection committee | Lot 3 gate |
